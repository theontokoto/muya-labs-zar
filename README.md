# MUYA LABS ZAR

Independent creative technology lab turning curiosity and everyday challenges into practical digital tools.

This repository contains the static public website. It introduces XiBaKaBaKa, our Windows and Android local-device connection app.

## Website

HTML, CSS and JavaScript; no build step. Enable GitHub Pages from the main branch and repository root.

The page uses a black background and randomly selects Gold, Space Purple, Royal Blue or Golden White when opened. Visitors can also select an accent in the footer.

## App download

The compiled public preview and user guide are provided as release assets. The app source, personal edition, signing keys and device-pairing files are not part of this website repository.

The public preview includes a manual acceptance-test checklist and known limitations. Use devices you own or are authorised to access, and approve permissions individually.
